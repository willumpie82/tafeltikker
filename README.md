# Tafeltikker

Self-hosted webapp for kids to practice multiplication tables (1–10) and typing.

- [`app/`](app/) — the web application (backend + frontend).
- [`infra/`](infra/) — provisioning for the Debian LXC container this runs on
  (Proxmox), so the environment can be rebuilt from git alone.
- [`doc/`](doc/) — original planning notes.

See `app/README.md` and `infra/README.md` for details on each part.
